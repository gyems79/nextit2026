# NextIT 2026

두두솔루션 온라인 세미나 랜딩 페이지입니다.

## 로컬 미리보기
`index.html` 파일을 브라우저에서 열면 확인할 수 있습니다.

## Vercel 배포
이 저장소를 Vercel 프로젝트로 Import하고 다음과 같이 설정합니다.

- Framework Preset: Other
- Build Command: 비워두기
- Output Directory: .
- Install Command: 비워두기
- Production Branch: main

GitHub의 `main` 브랜치에 변경 사항을 push하면 Vercel이 자동으로 새 배포를 생성합니다.

> 현재 신청 폼은 교육용 데모입니다. 입력한 정보는 저장되거나 서버로 전송되지 않습니다.
